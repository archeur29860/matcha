Blueprint `pictures_bp`, sans préfixe. Code : `back-matcha/routes/pictures_bp.py`.

## Récupérer une image

`GET /api/pictures/{filename}`

Sert un fichier du dossier `back-matcha/pictures` (`/app/pictures` dans le conteneur) avec `send_from_directory`. La réponse est le fichier brut, pas l'enveloppe JSON standard.

<ParamField path="filename" type="string" required>
  Nom du fichier, tel que stocké dans la colonne `pictures.url`.
</ParamField>

```bash
curl -O http://localhost:5000/api/pictures/f.jpg
```

Renvoie `404` si le fichier n'existe pas.

<Note>
  L'upload de photos n'est pas encore exposé par l'API. Les photos actuelles proviennent du [seed](/backend/seed), qui associe aux profils des fichiers choisis au hasard dans ce dossier.
</Note>
