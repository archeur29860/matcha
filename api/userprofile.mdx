Blueprint `userProfile_bp`, préfixe `/api/userprofile`. Code : `back-matcha/routes/userProfile_bp.py` et `back-matcha/services/userProfile_service.py`.

## Consulter un profil

`GET /api/userprofile/{user_id}/`

<ParamField path="user_id" type="string (UUID)" required>
  Profil à consulter.
</ParamField>

```bash
curl http://localhost:5000/api/userprofile/<uuid>/
```

Réponse `200` :

```json
{
  "success": true,
  "data": {
    "user_id": "<uuid>",
    "username": "jdupont_42",
    "first_name": "Jean",
    "last_name": "Dupont",
    "last_connection": "2026-11-10",
    "is_online": false,
    "age": "1995-04-12",
    "location": "Lyon",
    "gender": "Male",
    "gender_pref": ["Female"],
    "bio": "...",
    "popularity": 3,
    "tags": [{ "id": 1, "label": "vegan" }],
    "picture_profile_index": 0,
    "pictures": [{ "id": 0, "url": "f.jpg" }]
  },
  "error": null
}
```

<ResponseField name="age" type="date">
  Date de naissance (colonne `userProfile.age`), et non un âge calculé.
</ResponseField>

<ResponseField name="pictures" type="array">
  Photos de l'utilisateur. `url` est un nom de fichier à servir via [`/api/pictures/{filename}`](/api/pictures).
</ResponseField>

Renvoie `404 NOT_FOUND` si le profil n'existe pas.

## Lister les profils suggérés

`GET /api/userprofile/list/{user_id}/`

Renvoie les profils autres que `user_id`, en excluant les utilisateurs bloqués dans les deux sens et les profils sans photo de profil. La pagination se fait par curseur, trié par `user_id`.

<ParamField path="user_id" type="string (UUID)" required>
  Utilisateur pour qui la liste est générée.
</ParamField>

<ParamField query="limit" default="20" type="integer">
  Nombre de profils, borné entre 1 et 50.
</ParamField>

<ParamField query="cursor" type="string (UUID)">
  Valeur `next_cursor` de la page précédente.
</ParamField>

```bash
curl "http://localhost:5000/api/userprofile/list/<uuid>/?limit=20"
```

```json
{
  "success": true,
  "data": {
    "profiles": [
      {
        "user_id": "<uuid>",
        "username": "mlefevre_12",
        "age": "1998-02-03",
        "location": "Paris",
        "online": true,
        "tags": [{ "id": 2, "label": "geek" }],
        "bio": "...",
        "image": "f.jpg",
        "popularity": 4
      }
    ],
    "next_cursor": "<uuid>",
    "has_more": true
  },
  "error": null
}
```

<Note>
  Le tri par préférences, proximité, tags communs et popularité décrit dans le [cahier des charges](/cahier-des-charges) n'est pas encore implémenté dans cette requête.
</Note>
