---
title: "Tags"
description: "Créer et lister les tags d'intérêt réutilisables."
---

Blueprint `tags_bp`, préfixe `/api/tags`. Code : `back-matcha/routes/tags_bp.py` et `back-matcha/services/tags_service.py`.

Les tags sont stockés dans la table `tags` et référencés par identifiant dans `userProfile.tags`. Une liste de tags prédéfinis est insérée au démarrage de la base par `postgreSQL/tags.sql` (par exemple `vegan`, `geek`, `piercing`, `Jardinage`, `Cinéma`...).

## Créer un tag

`POST /api/tags/`

<ParamField body="label" type="string" required>
  Libellé du tag. Les espaces de début et de fin sont retirés. Non vide, 25 caractères maximum, unique.
</ParamField>

```bash
curl -X POST http://localhost:5000/api/tags/ \
  -H "Content-Type: application/json" \
  -d '{"label": "escalade"}'
```

Réponse `201` :

```json
{
  "success": true,
  "data": { "id": 70, "label": "escalade" },
  "error": null
}
```

| HTTP | Code | Cause |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | Corps absent, `label` manquant, vide ou trop long |
| 409 | `CONFLICT` | Le tag existe déjà |

## Lister les tags

`GET /api/tags/`

Renvoie tous les tags triés par libellé.

```bash
curl http://localhost:5000/api/tags/
```

```json
{
  "success": true,
  "data": [
    { "id": 19, "label": "Cinéma" },
    { "id": 15, "label": "Danse" }
  ],
  "error": null
}
```
