Blueprint `users_bp`, préfixe `/api/users`. Code : `back-matcha/routes/users_bp.py` et `back-matcha/services/users_service.py`.

Les mots de passe sont hachés avec `generate_password_hash` de Werkzeug avant insertion.

## Champs communs

Les deux routes valident les mêmes champs (fonction `validate_user_fields`). Chaque champ doit être une chaîne non vide (après `strip()`).

<ParamField body="email" type="string" required>
  Moins de 256 caractères. Unique.
</ParamField>

<ParamField body="username" type="string" required>
  Moins de 51 caractères. Unique.
</ParamField>

<ParamField body="last_name" type="string" required>
  Moins de 51 caractères.
</ParamField>

<ParamField body="first_name" type="string" required>
  Moins de 51 caractères.
</ParamField>

<ParamField body="password" type="string" required>
  Moins de 256 caractères.
</ParamField>

<Warning>
  Les erreurs de champ manquant, de type ou de champ vide sont renvoyées au format `{"error": "..."}` avec un code `400`, et non dans l'enveloppe standard. Seul le dépassement de longueur lève une `ValidationError` au format standard.
</Warning>

## Créer un utilisateur

`POST /api/users/`

```bash
curl -X POST http://localhost:5000/api/users/ \
  -H "Content-Type: application/json" \
  -d '{
    "email": "jean.dupont@example.com",
    "username": "jdupont",
    "last_name": "Dupont",
    "first_name": "Jean",
    "password": "MotDePasse!123"
  }'
```

Réponse `201` (objet brut, sans enveloppe) :

```json
{ "id": "<uuid>", "email": "jean.dupont@example.com" }
```

Renvoie `409 USER_ALREADY_EXISTS` si l'email ou le nom d'utilisateur est déjà pris.

## Modifier un utilisateur

`PUT /api/users/`

Remplace tous les champs de l'utilisateur (y compris le mot de passe, de nouveau haché). Tous les champs communs sont requis, plus :

<ParamField body="user_id" type="string (UUID)" required>
  Identifiant de l'utilisateur à modifier.
</ParamField>

```bash
curl -X PUT http://localhost:5000/api/users/ \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "<uuid>",
    "email": "jean.dupont@example.com",
    "username": "jdupont",
    "last_name": "Dupont",
    "first_name": "Jean",
    "password": "NouveauMotDePasse!123"
  }'
```

Réponse `200` :

```json
{
  "success": true,
  "data": { "id": "<uuid>", "email": "jean.dupont@example.com" },
  "error": null
}
```

| HTTP | Code | Cause |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | `user_id` invalide ou champ trop long |
| 404 | `USER_DOESNT_EXISTS` | Aucun utilisateur avec cet identifiant |
| 409 | `USER_ALREADY_EXISTS` | Email ou nom d'utilisateur déjà pris |
